Installation
============

1. Download `snack-1680.zip <../../../releases/snack-1680.zip>`_
2. Unzip snack-1680.zip
3. Change directory to snack-1680
4. Run the jar file
    * On linux: java -jar snack.jar
    * On windows: double click the jar file

Java 21 or greater is required on your operating system for software to run
